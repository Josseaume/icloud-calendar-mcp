# icloud-calendar-mcp

Serveur MCP local qui permet à Claude (Claude Code, Claude Desktop, Cowork) de lire
et d'écrire dans l'agenda iCloud, via le protocole CalDAV.

En cours de construction — la documentation complète arrive à la dernière étape.

## Après un clone

```sh
git config core.hooksPath .githooks   # active le garde-fou anti-mot de passe
```
